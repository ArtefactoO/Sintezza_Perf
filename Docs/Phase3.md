## Target and evidence

Forever interface 16001, upstream `Gethe/wow-ui-source` `forever` resolved to `bebcb6bf309cf41b41bd74f8ca651e6a105b2676` (1.60.1 / 70938). The pinned [AddOnProfiler declaration](https://github.com/Gethe/wow-ui-source/blob/bebcb6bf309cf41b41bd74f8ca651e6a105b2676/Interface/AddOns/Blizzard_APIDocumentationGenerated/AddOnProfilerDocumentation.lua) declares `MeasureCall(func, ...) -> result, ...returns`, with elapsedMilliseconds and allocated/deallocated bytes, and AllowedWhenUntainted secret arguments. Native allocation access is capability-probed with an inert function before use. Existence/declaration is not runtime certification; no game is launched under project policy.

CPU timing uses `debugprofilestop` across explicitly registered synchronous calls. Known self time subtracts only measured children; uninstrumented work remains included. Inclusive rows overlap and cannot be summed into total addon CPU. Native memory returns an API-created result table on each call; that allocation is part of the cost of the opt-in method. Allocation balance is not retained memory or proof of a leak. Production collection uses no whole-heap deltas, forced GC or scriptProfile changes.

The API accepts ordinary synchronous, unprotected, non-yielding functions. The guide excludes protected paths and secret arguments/results. Invalid metrics stop collection with a partial report while preserving the original function's return/error behavior. Native Perf time and accounted service time may overlap; neither their sum nor their difference establishes total probe overhead. The guard stops at more than 1 ms mean accounted service work over 60 frames or more than 20 ms for an accounted pass/frame, not a guaranteed ceiling on all Perf work.
